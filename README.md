UC Berkeley Pacman AI Projects (Spring 2023)

This repository contains my solutions to the **UC Berkeley CS188: Artificial Intelligence** Pacman projects (Spring 2023 term).  
Each module focuses on a different aspect of AI — including **search algorithms**, **adversarial agents**, and **reinforcement learning** — implemented in Python.

These modules were very helpful in order to visulaize various theoretical topics in the form of a game. 

---

## Project Overview

### 1. **Search**
Implemented classical search algorithms to help Pacman navigate mazes efficiently. The game files provides tools to see which areas are dicovered by the agent in order to decide upon a optimal path which is very helpful in visualising the algorithms implemented.

- Algorithms: **Depth-First Search (DFS)**, **Breadth-First Search (BFS)**, **Uniform Cost Search (UCS)**, and **A\***.
- Focus: Understanding heuristic design and optimal pathfinding.

### 2. **Adversarial Agents**
Developed intelligent ghost and Pacman agents for competitive gameplay. This modeule gives a better understanding of how adverserial agents behave when following minimax strategy

- Techniques: **Minimax**, **Alpha-Beta Pruning**, and **Expectiminimax**.
- Focus: Game tree search, evaluation functions, and decision-making under uncertainty.

### 3. **Reinforcement Learning**
Deployed value iteration , policy iteration algorithms to train agent through markov decision process. Also implemented Q-learning in a grid world which can also be applied to a crawler that learns to walk.

- Algorithms: **Value Iteration**, **Policy Iteration**, and **Q-Learning**.
- Focus: Applying Markov Decision Processes (MDPs) and reward-based learning.
